# ☁️ Descomplicando a Computação em Nuvem

Este repositório contém minhas notas de estudo e resumos sobre os fundamentos de Cloud Computing. O objetivo é documentar o aprendizado sobre modelos de implantação, conceitos financeiros (CapEx e OpEx) e a exploração da plataforma Microsoft Azure.

---

## 🚀 Resumo do Aprendizado

### 1. Modelos de Implantação
Existem três formas principais de consumir serviços de nuvem:

* **Pública:** Recursos compartilhados via internet (Ex: Azure). Baixo custo e alta escalabilidade.
* **Privada:** Infraestrutura dedicada exclusivamente a uma organização. Maior controle e segurança.
* **Híbrida:** Integração entre nuvens públicas e privadas, permitindo que dados e aplicativos se movam entre elas conforme a necessidade.

### 2. Gestão Financeira: CapEx vs. OpEx
A migração para a nuvem altera radicalmente a forma como as empresas investem em tecnologia:

| Modelo | Definição | Exemplo na Nuvem |
| :--- | :--- | :--- |
| **CapEx** | Investimento em bens físicos (Capital). | Compra de hardware e infraestrutura de data center. |
| **OpEx** | Gastos operacionais contínuos (Operacional). | Pagamento mensal baseado no consumo (Pay-as-you-go). |

## 🔷 Microsoft Azure: Visão Geral

O **Portal do Azure** é a interface centralizada para gerenciar todos os serviços da Microsoft Cloud. Minhas principais percepções sobre a ferramenta foram:

-   **Interface Unificada:** Um único lugar para criar, gerenciar e monitorar recursos.
-   **Flexibilidade:** Suporte a diversas linguagens, frameworks e sistemas operacionais.
-   **Gestão de Custos:** Ferramentas nativas para prever e limitar gastos operacionais.
